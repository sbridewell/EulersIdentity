# Comparison of large language models for use with GitHub Copilot

## Question

GitHub Copilot can be used with a range of different large language models (LLMs).
- GPT-4o
- GPT-4.1
- GPT-5 mini
- GPT-5
- o3-mini
- Claude Sonnet 3.5
- Claude Sonnet 3.7
- Claude Sonnet 3.7 Thinking
- Claude Sonnet 4
- Gemini 2.0 Flash
- Gemini 2.5 Pro

This document compares these models based on the following criteria to help me choose the best one for my needs, as a holder of a GitHub Copilot Pro subscription.
- Correctness: How accurate and reliable are the responses generated by the model?
- Price: What is the cost associated with using the model, especially in relation to my GitHub Copilot Pro subscription? Explicitly call out any per-usage costs and any other costs over and above the cost of the Pro subscription, or whether the model is cost-free to use.
- Speed: How quickly does the model generate responses?
- Anti-patterns: LLMs used by AI coding assistants are often trained on public code repositories, and the code in those repositories isn't always good quality. How good is the model at identifying and filtering out potential anti-patterns?
